### Data Engineer | Cloud Data Platforms (Azure, AWS & GCP) | Data Analytics | Business Intelligence
---
## About Me
I am a Data Engineer focused on designing and building reliable, scalable data pipelines that power analytics and decision-making.
I specialize in cloud data engineering on **Microsoft Azure** (Synapse Analytics, Event Hub), **AWS** (S3, Glue, Redshift, Lambda, EMR, Kinesis, Athena, Step Functions), and **Google Cloud Platform** (BigQuery, Dataflow, Dataproc, Pub/Sub, Cloud Composer, Cloud Storage, Cloud Functions, Vertex AI), building ETL/ELT pipelines, data warehouses, and lakehouse architectures using tools like Databricks, Snowflake, PySpark, and Airflow. I design dynamic, parameter-driven, configuration based pipelines that scale across datasets and environments. I also bring a strong analytics background developing dashboards, automated reporting, and machine learning models (PyTorch, scikit-learn) on top of the data infrastructure I build.
My goal is to help organizations turn raw, disconnected data into clean, trustworthy, and accessible data products that drive better decisions at scale.
